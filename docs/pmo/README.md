## Cadência sugerida

- **Status semanal**: atualizar `status-report.md` toda segunda; circular por e-mail.
- **Risk review**: revisar `risk-register.md` quinzenalmente.
- **Steering committee**: mensal, usando `status-report.md` + `kpi-baseline.md`.
- **Decision log**: atualizar imediatamente após cada decisão tomada (não esperar reunião).
