# Atendimento de Incidentes Operacionais

## Primeira triagem

O Suporte deve registrar impacto, usuario afetado, horario, sistema e tentativa ja executada antes de escalar para outro setor.

## Quando envolver seguranca

Se houver indicio de conta comprometida, anomalia de acesso, compartilhamento de credenciais ou comportamento fora do padrao, a triagem precisa envolver Seguranca imediatamente.

## Quando envolver desenvolvimento

Falhas de API, regressao de deploy, erro de integracao ou comportamento tecnico repetitivo devem ser escalados para Desenvolvimento com evidencias objetivas.
