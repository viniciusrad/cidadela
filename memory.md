## Operational Notes

- Docker local em container: sempre use `-f docker-compose.local.yml`. O `app` local e `next dev` com bind mount; para fonte nova que nao apareceu na tela, reinicie o servico `app` local antes de tentar rebuild. Reserve `up -d --build app` com o Compose local para imagem/configuracao e atualize o volume `app_node_modules` dentro do container quando `package*.json` mudar.
- Only explicit development-sector commands should trigger `human-in-captcha` automations. Generic analysis questions must continue through the normal chat/RAG path.
- Non-development sectors must not queue automations directly; they create an approval prompt and require a later response in the format `sim, motivo: ...` or a cancellation.
- Container-to-container calls should use `HUMAN_CAPTCHA_API_URL=http://human-automation-api:3001` on the external Docker network `pfrm-local-internal`.
- Se `npm run dev` falhar com `Error: Can't resolve 'tailwindcss'` tentando buscar o pacote em um diretório pai (ex: `C:\temp\repo\pfrm-secure-chat`), o cache do Turbopack (`.next/`) está corrompido com resoluções de caminhos absolutos antigas. A solução é deletar a pasta `.next` e rodar o dev server novamente.
