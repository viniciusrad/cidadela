Preço - Unificado (carga enviada 7h)

Processo de inclusão:
1- Verificar código do fornecedor + SSF 
2- Solicitar via demanda aa parametrização do SAP e abrir PBI para parametrizar a variável no job web
3- Incluir carga de desconto em QA  pelo comercial na transação zsd244
4- Validar carga de dados em QA com indústria
5- Após ok, solicitar envio para ambiente de produção, a ser realizado pelo time web e SAP.
